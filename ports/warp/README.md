# Fadetouched for Warp

Copy `fadetouched.yaml` into Warp's custom theme directory:

- Windows: `%APPDATA%\warp\Warp\data\themes\`
- Linux: `${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/themes/`
- macOS: `$HOME/.warp/themes/`

Restart Warp if the theme does not appear, then select Fadetouched under **Settings > Appearance > Themes**.
