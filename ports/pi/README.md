# Fadetouched for Pi

## Install

1. Copy [`fadetouched.json`](fadetouched.json) to
   `~/.pi/agent/themes/fadetouched.json`.
2. Open `~/.pi/agent/settings.json` and set `"theme": "fadetouched"`.
3. Restart Pi.

This port follows the theme format used by
[`earendil-works/pi`](https://github.com/earendil-works/pi).
